## Overview

Implementation of several cryptographic primitives and hardware architectures.

## Implemented Designs

- AES encryption on Artix-7 FPGA
- A5/1 stream cipher
- Trivium stream cipher
- Keccak hash function
- Kogge-Stone adder
- Karatsuba multiplier

## Technologies

- VHDL
- Verilog
- FPGA design
