## Overview

OPUF is a Physical Unclonable Function architecture designed to improve resilience against machine-learning modeling attacks.

The project explores architectural obfuscation techniques to increase unpredictability and reduce attack accuracy.

## Research Contributions

- Designed an obfuscated PUF architecture
- Evaluated resistance against machine-learning attacks
- Studied PUF quality metrics including uniqueness and randomness

## Technologies

- Verilog
- FPGA-based evaluation
- Machine learning attacks
- Hardware security analysis

This work resulted in the publication:

**"OPUF: Obfuscated PUF Against Machine Learning Modeling Attacks"**

Journal of Circuits, Systems and Computers, 2025.
