## Overview

Implementation and security evaluation of the ASCON lightweight authenticated encryption algorithm.

This project focuses on understanding and evaluating implementation-level leakage through power analysis and machine-learning-based side-channel attacks.

## Objectives

- Implement ASCON cryptographic components
- Analyze power leakage behavior
- Evaluate resistance against side-channel attacks
- Explore machine-learning-assisted attack methodologies

## Technologies

- Rust
- Cryptographic implementations
- Power trace analysis
- Side-channel evaluation
- Machine learning


The project is part of my ongoing research interest in secure cryptographic hardware implementations.
